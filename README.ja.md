## v0.2.0 の新機能：多言語とソフトウェア更新

### 多言語（外付け言語パック）

- 簡体字中国語は**ソース言語**であり、メインプログラムに直接組み込まれているため、言語パックをインストールしなくても正常に使用できます。
- 繁体字中国語、日本語、英語は `.meowlang`（JSON テキスト）形式の言語パックとしてプログラムディレクトリの `lang` フォルダに配置され、公式がパッケージに同梱して配布します。
- 設定ページの「言語 / Language」カード：
  - **言語を選択**：言語管理ウィンドウを開き、`lang` ディレクトリ内のすべての言語パックを一覧表示します。詳細を確認して選択した言語を読み込むことができ、読み込むと自動的に再起動して反映されます。
  - **言語パックをインストール**：`.meowlang` ファイルを選択し、フィールドと対応バージョンを検証したうえで詳細（パッケージ名、作成者、対応バージョン、インストール日時、言語の種類、言語コード、ファイルサイズ、概要、作者のウェブサイト）を表示します。公式言語パックには緑色の盾のアイコンが付き、サードパーティの言語パックは再確認が必要です。インストールにはプログレスバーが付き、成功時は「言語パックのインストールに成功しました！」と表示され、失敗時は理由とログのパスが表示されます。
  - **同名言語パックの更新／ダウングレード**：バージョン番号を自動的に比較し、再確認を行います。作者または作者のウェブサイトが一致しない場合は上書きを拒否し、古いパッケージを手動で削除する必要があります。
  - **対応バージョン**：`*`、`>=0.2.0`、`0.2.0 | 0.2.1 | 0.2.2` などの複数バージョンの記法をサポートします。
- 公式言語パックは `v1.1.0-lang` として別途公開され、言語パックだけを更新したいユーザーが単独でダウンロードできます。

### ソフトウェア更新

- 設定ページの「ソフトウェア更新」カードに「更新を確認」を追加しました。公式の更新インターフェースにリクエストし、バージョンを比較したうえで最新バージョン番号、更新内容、「公式サイトから新しいバージョンを入手」ボタンを表示します。すでに最新の場合は、現在のバージョンであることを表示します。
- **サポート終了バージョンの検出**：インターフェースが返すサポート対象外バージョンのリストに現在のバージョンが含まれている場合、起動時に「このバージョンはサポートを終了しました」という強制アップデートの通知が表示され、更新するまで本プログラムを継続して使用できません。

## 安全設計

- すべての変更、削除、クリーンアップ操作は**いずれもユーザーによる手動確認が必要**で、自動的に実行されるロジックは一切ありません。残留項目と使用中項目はデフォルトではチェックされていません。
- 内蔵ブラックリスト：システムの中核ディレクトリ（`C:\Windows`、`System32`、`WinSxS`）およびシステムの中核プロセスは強制終了できません。
- パッカー、難読化、自己解凍型の悪意あるロジックは使用していません。低レベルでは Microsoft ネイティブの Win32 API（RestartManager、MoveFileEx、Registry など）を呼び出すだけです。
- 言語パックは `lang` ディレクトリにコピーされる JSON テキストにすぎず、インストールの過程で言語パック内のコードが実行されることはありません。

## ビルドと実行

### 環境
- Visual Studio 2022 Community（「.NET デスクトップ開発」ワークロードを含む）
- .NET 8 SDK
- NuGet で HandyControl 3.5.1 を復元

### 直接実行（デバッグ）
VS で `LetsMeowToolbox.sln` を開き、F5 で `LetsMeowToolbox.App` を実行します。ビルド時に高危険プラグインは自動的にメインプログラムの出力ディレクトリの `plugins` フォルダにコピーされ、`lang/**/*.meowlang` も出力ディレクトリの `lang/` に自動的にコピーされます。

### 単一ファイル発行（2 つのモード）

**モード 1：単一ファイル・ランタイム依存（小さい、約 10〜20MB、対象 PC に .NET 8 デスクトップランタイムが必要）**
```powershell
./build/publish-framework-dependent.ps1
# 产物：dist/framework-dependent/LetsMeowToolbox.exe + plugins/ + lang/
```

**モード 2：単一ファイル・自己完結（大きい、約 90〜110MB、対象 PC に .NET は不要）**
```powershell
./build/publish-self-contained.ps1
# 产物：dist/self-contained/LetsMeowToolbox.exe + plugins/ + lang/
```

手動で実行することもできます：
```bash
dotnet publish src/LetsMeowToolbox.App -c Release -r win-x64 \
  -p:PublishSingleFile=true --self-contained false -o dist/framework-dependent
dotnet publish src/LetsMeowToolbox.App -c Release -r win-x64 \
  -p:PublishSingleFile=true --self-contained true  -o dist/self-contained
```
発行後、`LetsMeowToolbox.Plugins.HighRisk.dll` を `dist/…/plugins/` にコピーすれば高危険プラグインゾーンが有効になります。`lang/` ディレクトリは csproj によって自動的にコピーされるため、手動で処理する必要はありません。

## よくある質問（GUI が開けない場合の調べ方）

> [!WARNING]
> **作者からの注意：**
> 問題が発生した場合は、まず[**オンラインドキュメントをご覧ください**](https://doc.lets-meow-toolbox.hatasoft365.top/)。**オンラインドキュメントで 99% の問題は解決できます**！問題が発生したときにドキュメントを読まずに立てた Issue は、直接クローズします！

本プログラムには**グローバル例外キャッチとログ**が組み込まれています。起動時または実行中にエラーが発生した場合は、エラーダイアログが表示され、ログが書き込まれるため、「何も起きずに開けない」ことはありません。

- **ログの場所**：`%LocalAppData%\LetsMeowToolbox\logs\meow-日期.log`
  （エクスプローラーのアドレスバーに `%LocalAppData%\LetsMeowToolbox\logs` を貼り付けて Enter を押せば開けます）
- **フレームワーク依存版が開けない場合**：[.NET 8 デスクトップランタイム](https://dotnet.microsoft.com/download/dotnet/8.0)（「.NET Desktop Runtime 8.x」を選択）を先にインストールしてください。ランタイムをインストールしたくない場合は、**自己完結（self-contained）**版をそのままご使用ください。ランタイムを同梱しており、ダブルクリックですぐに使えます。
- **テーマについて**：Win11 以外のシステムでは自動的に単色背景にフォールバックする場合がありますが、使用には影響しません。
- **言語パック関連**：言語パックのインストール失敗、切り替え後に反映されないなどの問題については、[設定とこのプログラムについて](https://doc.lets-meow-toolbox.hatasoft365.top/docs/settings.html)をご覧ください。
